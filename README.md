# Figma Frontend - Lead Sources UI

A modern React + TypeScript web application built with Vite and Tailwind CSS, featuring the "Connect the channels you already use" lead sources integration cards.

## Features

- **Lead Sources Management**: Interactive cards for Google Ads, WhatsApp, Meta Ads, and other marketing channels.
- **Fast Development**: Powered by Vite and React 18.
- **Styling**: Tailwind CSS for responsive and clean layout.
- **Type Safety**: Built with TypeScript.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
git clone <repository-url>
cd figma_frontend
npm install
```

### Running Locally

```bash
npm run dev
```

The application will be available at `http://localhost:5173`.

### Building for Production

```bash
npm run build
```
