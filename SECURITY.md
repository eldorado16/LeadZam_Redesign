# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not open a public issue. Instead, report it privately:

- Use GitHub Private Vulnerability Reporting on this repository (under the **Security** tab).
- Or email the project maintainer directly.

Please include:
- A description of the vulnerability.
- Steps or proof-of-concept to reproduce the issue.
- Potential impact and affected components.

We will acknowledge receipt within 48 hours and work on a resolution.
